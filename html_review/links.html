<a>

01

Definition

Creates a hyperlink to another page, a location in a page, or a file. Link text should describe the destination.

Attributes

Attributes of <a>
AttributeRole
hrefThe destination URL or fragment identifier.
targetWhere to open the destination, such as _blank for a new tab.
relThe relationship to the destination; noopener protects a new tab.
downloadRequests a download for a same-origin resource.

Example HTML code

<p><a href="#tag-img">Jump to the image example</a></p>
<p><a href="images/chime.wav" download>Download the audio sample</a></p>
<p><a href="images/html-demo.webm">Open the video sample</a></p>

<img>

02

Definition

Embeds an image in the document. Meaningful alternative text describes its content when it cannot be seen.

Attributes

Attributes of <img>
AttributeRole
srcThe image file URL.
altA text alternative; use an empty value for a purely decorative image.
width / heightIntrinsic dimensions in CSS pixels, used to reserve space.
loadinglazy defers loading until the image approaches the viewport.

Example HTML code

<img src="images/study-desk.svg"
     alt="A book, a plant and a laptop displaying HTML on a study desk"
     width="640" height="400" loading="lazy">

Result Live preview

<audio>

03

Definition

Embeds an audio player. A local file can be played in the page or linked for download.

Attributes

Attributes of <audio>
AttributeRole
srcThe audio file URL.
controlsShows the browser playback controls.
preloadA loading hint: none, metadata or auto.

Example HTML code

<audio controls preload="metadata" src="images/chime.wav">
  <a href="images/chime.wav">Download the audio</a>
</audio>
<p>Audio description: three short, ascending chime notes.</p>

Result Live preview

<video>

04

Definition

Embeds a video player. Supply controls so the user can choose when to play it.

Attributes

Attributes of <video>
AttributeRole
srcThe video file URL.
controlsShows native playback controls.
posterAn image displayed before playback.
widthThe display width in CSS pixels.

Example HTML code

<video controls width="640" preload="metadata"
       poster="images/video-poster.svg" src="images/html-demo.webm">
  <track kind="captions" src="images/captions.vtt"
         srclang="en" label="English" default>
  <a href="images/html-demo.webm">Download the video</a>
</video>
