Links, images and media

Add a link, show a picture, or play an audio or video file.

<a>

Definition

Creates a link to another page or file.

Attributes

AttributeRole
hrefThe page or file to open.
targetUse _blank to open a new tab.
downloadAsks the browser to download a local file.

Example (code)

<p><a href="lists.html">Go to the lists page</a></p>
<p><a href="images/chime.wav" download>Download audio</a></p>
<p><a href="images/html-demo.webm">Open video</a></p>

Example (result)

Go to the lists page

Download audio

Open video

<img>

Definition

Shows an image. It has no closing tag.

Attributes

AttributeRole
srcThe image file path.
altText that describes the image.
widthThe image width in pixels.

Example (code)

<img src="images/study-desk.svg"
     alt="A laptop, a book and a plant on a desk" width="480">

Example (result)

<audio>

Definition

Adds an audio player to the page.

Attributes

AttributeRole
srcThe audio file path.
controlsShows the play and volume buttons.

Example (code)

<audio controls src="images/chime.wav">
  <a href="images/chime.wav">Download audio</a>
</audio>
<p>Sound: three short musical notes.</p>

Example (result)

Sound: three short musical notes.

<video>

Definition

Adds a video player to the page.

Attributes

AttributeRole
srcThe video file path.
controlsShows the player controls.
widthThe player width in pixels.

Example (code)

<video controls width="480" src="images/html-demo.webm">
  <track src="images/captions.vtt" kind="captions"
         srclang="en" label="English" default>
  <a href="images/html-demo.webm">Download video</a>
</video>
