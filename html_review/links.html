Links, images and media

Add a link, show a picture, or play an audio or video file.

<a>

Definition

Creates a link to another page or file.

Attributes

AttributeRole
hrefThe page or file to open.

Example (code)

<a href="text.html">Open the text page</a>

Example (result)

Open the text page

<img>

Definition

Shows an image. It has no closing tag.

Attributes

AttributeRole
srcThe image file path.
altText that describes the image.
widthThe image width in pixels.

Example (code)

<img src="images/study-desk.svg"
     alt="A laptop, a book and a plant on a desk" width="480">

Example (result)

<audio>

Definition

Adds an audio player to the page.

Attributes

AttributeRole
srcThe audio file path.
controlsShows the play and volume buttons.

Example (code)

<audio controls src="images/chime.wav"></audio>

Example (result)

Sound: three short musical notes.

<video>

Definition

Adds a video player to the page.

Attributes

AttributeRole
srcThe video file path.
controlsShows the player controls.
widthThe player width in pixels.

Example (code)

<video controls width="400" src="images/html-demo.webm"></video>

Example (result)
