Multimedia

Add audio, video, captions and other content to a page.

<audio>

Definition

Plays an audio file on the page.

Attributes

AttributeRole
srcThe audio file path.
controlsShows playback controls.
loopRepeats the audio.

Example (code)

<audio controls src="images/chime.wav">
  <a href="images/chime.wav">Download audio</a>
</audio>
<p>Sound: three short musical notes.</p>

Example (result)

Sound: three short musical notes.

<video>

Definition

Plays a video file on the page.

Attributes

AttributeRole
srcThe video file path.
controlsShows playback controls.
posterAn image shown before the video starts.

Example (code)

<video controls width="480" src="images/html-demo.webm"
       poster="images/video-poster.svg">
  <track src="images/captions.vtt" kind="captions"
         srclang="en" label="English" default>
  <a href="images/html-demo.webm">Download video</a>
</video>

<source>

Definition

Provides a file for an audio or video player to use.

Attributes

AttributeRole
srcThe file path.
typeThe file type, for example audio/wav.

Example (code)

<audio controls>
  <source src="images/chime.wav" type="audio/wav">
  <a href="images/chime.wav">Download audio</a>
</audio>
<p>Sound: three short musical notes.</p>

Example (result)

Sound: three short musical notes.

<track>

Definition

Adds captions to a video from a text file.

Attributes

AttributeRole
srcThe caption file path.
kindThe type of text, such as captions.
srclangThe caption language.
defaultTurns on this track by default.

Example (code)

<video controls width="480" src="images/html-demo.webm">
  <track src="images/captions.vtt" kind="captions"
         srclang="en" label="English" default>
  <a href="images/html-demo.webm">Download video</a>
</video>
<p>Video text: HTML gives a page structure. CSS gives it style. Build, then review.</p>

Example (result)

Video text: HTML gives a page structure. CSS gives it style. Build, then review.

<iframe>

Definition

Shows another HTML page inside the current page.

Attributes

AttributeRole
srcThe page to display.
titleA short description of the embedded page.

Example (code)

<iframe src="examples/page.html" title="My first HTML page"></iframe>

Example (result)

<figure>

Definition

Groups an image and its caption.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<figure>
  <img src="images/study-desk.svg" alt="A laptop, a book and a plant" width="480">
  <figcaption>My study desk.</figcaption>
</figure>

Example (result)
