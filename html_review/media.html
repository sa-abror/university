<audio>

01

Definition

Embeds sound, with optional browser playback controls. This sample is a locally generated three-note chime.

Attributes

Attributes of <audio>
AttributeRole
controlsShows play, pause, seek and volume controls.
preloadA hint about how much to load before playback.
loopRepeats the audio after it ends.
mutedStarts with audio muted.

Example HTML code

<audio controls preload="metadata">
  <source src="images/chime.wav" type="audio/wav">
  <a href="images/chime.wav">Download the chime</a>
</audio>
<p>Audio description: three short, ascending chime notes; no speech.</p>

<video>

02

Definition

Embeds moving images. Controls allow the user to start playback; a poster provides a preview.

Attributes

Attributes of <video>
AttributeRole
controlsShows playback controls.
posterThe preview image URL.
width / heightThe display dimensions in CSS pixels.
playsinlineRequests playback within the page on mobile devices.
preloadnone, metadata or auto loading hint.

Example HTML code

<video controls width="640" preload="metadata" playsinline
       poster="images/video-poster.svg">
  <source src="images/html-demo.webm" type="video/webm">
  <track kind="captions" src="images/captions.vtt"
         srclang="en" label="English" default>
  <a href="images/html-demo.webm">Download the video</a>
</video>
<p>Transcript: HTML gives a page structure. CSS gives it style. Build, then review.</p>

Result Live preview

Transcript: HTML gives a page structure. CSS gives it style. Build, then review.

<source>

03

Definition

Offers a media resource to audio or video, or an image candidate set to picture. The browser chooses a supported resource.

Attributes

Attributes of <source>
AttributeRole
srcResource URL inside audio or video.
typeThe resource MIME type.
srcsetImage candidates inside picture.
mediaA media query controlling when a picture source is used.

Example HTML code

<audio controls preload="metadata">
  <source src="images/chime.wav" type="audio/wav">
  <a href="images/chime.wav">Download the chime</a>
</audio>
<p>Audio description: three ascending notes.</p>

Result Live preview

Audio description: three ascending notes.

source has no visible output of its own; the parent player uses the resource it supplies.

<track>

04

Definition

Adds timed text, such as captions, to a video or audio element. A WebVTT file contains the cues and timestamps.

Attributes

Attributes of <track>
AttributeRole
srcThe .vtt timed-text file URL.
kindThe kind of text, such as captions or subtitles.
srclangThe language of the timed text.
labelThe track name shown in the player.
defaultSelects the track unless user preferences choose another.

Example HTML code

<video controls width="640" preload="metadata"
       src="images/html-demo.webm" poster="images/video-poster.svg">
  <track src="images/captions.vtt" kind="captions"
         srclang="en" label="English" default>
</video>
<p>Transcript: HTML gives a page structure. CSS gives it style. Build, then review.</p>

Result Live preview

Transcript: HTML gives a page structure. CSS gives it style. Build, then review.

Play the clip to see the timed captions. Use a local HTTP server so browsers can load the WebVTT file reliably.

<iframe>

05

Definition

Embeds another HTML document in its own browsing context. A descriptive title helps users identify the frame.

Attributes

Attributes of <iframe>
AttributeRole
srcThe URL of a document to embed.
srcdocInline HTML for the embedded document; takes precedence over src.
titleAn accessible name describing the frame.
sandboxRestricts capabilities; an empty value applies all restrictions.
loadinglazy delays off-screen frames.

Example HTML code

<iframe title="A small embedded HTML document" sandbox
  srcdoc="&lt;!DOCTYPE html&gt;&lt;html lang=&quot;en&quot;&gt;&lt;head&gt;&lt;meta charset=&quot;UTF-8&quot;&gt;&lt;title&gt;Embedded example&lt;/title&gt;&lt;link rel=&quot;stylesheet&quot; href=&quot;css/style.css&quot;&gt;&lt;/head&gt;&lt;body class=&quot;document-example&quot;&gt;&lt;h1&gt;Hello from an iframe&lt;/h1&gt;&lt;p&gt;This is a separate document.&lt;/p&gt;&lt;/body&gt;&lt;/html&gt;">
</iframe>

Result Live preview

<picture>

06

Definition

Offers alternative images for different display conditions. Always end with an img element as the fallback and source of alternative text.

Attributes

Attributes of <picture>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<picture>
  <source media="(max-width: 600px)" srcset="images/study-desk-small.svg">
  <img src="images/study-desk.svg"
       alt="A laptop, book and plant on a study desk" width="640" height="400">
</picture>

Result Live preview

Resize the browser below 600 pixels to use the compact illustration.

<figure>

07

Definition

Groups self-contained content, such as an illustration, with an optional caption.

Attributes

Attributes of <figure>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<figure>
  <img src="images/study-desk.svg" alt="A laptop, book and plant"
       width="640" height="400">
  <figcaption>A simple workspace for learning HTML.</figcaption>
</figure>

Result Live preview

<figcaption>

08

Definition

Provides the caption for its parent figure. Place it first or last inside the figure.

Attributes

Attributes of <figcaption>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<figure>
  <img src="images/study-desk-small.svg" alt="An HTML document on a laptop"
       width="640" height="400">
  <figcaption>Figure 1. Start with one HTML document.</figcaption>
</figure>
