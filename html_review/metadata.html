Page metadata

Metadata gives the browser information about the page.

<title>

Definition

Sets the text shown on the browser tab. It goes inside head.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<title>Metadata | HTML Review</title>

Example (result)

The browser tab is named Metadata | HTML Review.

This title is already written in the head of this page.

<meta>

Definition

Gives the browser information such as character encoding and screen settings.

Attributes

AttributeRole
charsetUTF-8 supports text in different languages.
nameThe name of a setting, such as viewport.
contentThe value of that setting.

Example (code)

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">

Example (result)

Hello! Salom! Привет!

Both tags are already in the head. UTF-8 supports the text above, and viewport helps the page fit a phone screen. The tags themselves are not visible.

<link>

Definition

Connects the page to a file such as an external stylesheet.

Attributes

AttributeRole
relUse stylesheet to connect a CSS file.
hrefThe path to that file.

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

This text uses our CSS file.

This link is already in the head. It loads the colours and other styles used on this page.
