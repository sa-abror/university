Page metadata

Metadata gives the browser information about the page.

<title>

Definition

Sets the text shown on the browser tab. It goes inside head.

Attributes

AttributeRole
None requiredA title works without any attributes.

Example (code)

<title>My first page</title>

Example (result)

Open the example page

The title is not a heading. Open the example page to see its title on the browser tab.

<meta>

Definition

Gives the browser information such as character encoding and screen settings.

Attributes

AttributeRole
charsetUTF-8 supports text in different languages.
nameThe setting name, for example viewport.
contentThe value of the setting.

Example (code)

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">

Example (result)

Open the example page

These tags do not show text. They help the browser display the page correctly.

<link>

Definition

Connects the page to a file such as an external stylesheet.

Attributes

AttributeRole
relUse stylesheet to connect a CSS file.
hrefThe path to that file.

Example (code)

<link rel="stylesheet" href="../css/style.css">

Example (result)

Open the example page

The example is in the examples folder, so ../ goes up one folder to find css/style.css.
