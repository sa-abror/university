CHAPTER 09 / 09 Metadata

Behind every good page.

Titles, character encoding and resource links describe a document to the browser before its content appears.

4 tag guidesCode + live examplesHTML & CSS

In this chapter

<title> <meta> <link> <base>

<title>

01

Definition

Sets the document title used by a browser tab, history and bookmarks. It belongs in head and contains plain text.

Attributes

Attributes of <title>
AttributeRole
langOverrides the language of the title text if necessary.
dirSpecifies text direction.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My HTML notebook</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <h1>A page with a title</h1>
  <p>The document title is “My HTML notebook”.</p>
</body>
</html>

Result Live preview

title does not paint a heading. This frame has its own document title; the parent browser tab keeps “Metadata | HTML Review”.

<meta>

02

Definition

Supplies metadata such as character encoding, a description and viewport settings. This void element belongs in head.

Attributes

Attributes of <meta>
AttributeRole
charsetDeclares UTF-8 character encoding.
nameThe metadata name, such as description or viewport.
contentThe value for a named metadata entry.
http-equivA supported document processing directive.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Metadata example</title>
  <link rel="stylesheet" href="css/style.css">
  <meta name="description" content="An HTML metadata example.">
</head>
<body class="document-example">
  <h1>Characters, correctly displayed</h1>
  <p>UTF-8: café · Привет · Salom</p>
</body>
</html>

Result Live preview

Metadata is not visible by itself. The result shows UTF-8 text; the viewport declaration supports mobile layouts.

<link>

03

Definition

Describes a relationship to another resource, such as a stylesheet or icon. A stylesheet link loads external CSS.

Attributes

Attributes of <link>
AttributeRole
relThe relationship, such as stylesheet or icon.
hrefThe resource URL.
mediaA media query restricting when a stylesheet applies.
typeA MIME-type hint for the resource.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Linked CSS example</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <h1>One shared stylesheet</h1>
  <p class="demo-box">This box uses css/style.css.</p>
</body>
</html>

Result Live preview

The link itself has no visible content. The box demonstrates the styles loaded from the same external CSS file as every chapter.

<base>

04

Definition

Sets the base URL for relative links in a document. Use at most one base element, before elements with relative URLs.

Attributes

Attributes of <base>
AttributeRole
hrefThe base URL used to resolve relative references.
targetThe default browsing context for links and forms.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Base URL example</title>
  <base href="images/">
  <link rel="stylesheet" href="../css/style.css">
</head>
<body class="document-example">
  <img src="study-desk.svg" alt="A laptop, book and plant" width="640" height="400">
</body>
</html>

Result Live preview

The image resolves to images/study-desk.svg. This isolated frame keeps the base URL from changing links on the review page.
