CHAPTER 06 / 09 Forms

Make room for input.

Labels, controls and groups help people enter information. Try the native browser controls below.

<form>

01

Definition

Groups controls used to submit information. The action and method define the submission destination and HTTP method.

Attributes

Attributes of <form>
AttributeRole
actionThe URL that receives the submitted values.
methodget puts values in the URL; post sends them in the request body.
autocompleteHints whether the browser may suggest saved values.

Example HTML code

<form action="forms.html#tag-form" method="get">
  <label for="form-topic">Choose a topic</label>
  <select id="form-topic" name="topic">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
  </select>
  <button type="submit">Try GET submission</button>
</form>

Result Live preview

Submitting reloads this page with ?topic=html or ?topic=css in the address. This static demonstration has no server processing and stores no form submissions.

<label>

02

Definition

Gives a form control an accessible name. Clicking the label focuses or toggles its associated control.

Attributes

Attributes of <label>
AttributeRole
forMatches the id of the control it describes.

Example HTML code

<label for="label-name">Practice name</label>
<input id="label-name" type="text" placeholder="Type a sample name">

Result Live preview

<input>

03

Definition

Creates a single control whose type determines its behaviour. It is a void element.

Attributes

Attributes of <input>
AttributeRole
typeThe control type, such as text, email, number or checkbox.
nameThe key used when submitting the control value.
valueThe initial value, or the submitted value of a checkbox.
requiredRequires a value before its form can be submitted.
placeholderA short hint; it does not replace a label.
min / maxLimits for numeric or date controls.

Example HTML code

<label for="input-email">Practice email</label>
<input id="input-email" name="email" type="email"
       placeholder="student@example.com" required>
<label>
  <input id="input-check" type="checkbox" name="practice" value="yes">
  I have tried this example
</label>

Result Live preview

These individual controls are a local practice example. They do not submit any data.

<button>

04

Definition

Creates a button. Set its type explicitly inside a form to avoid unintended submission.

Attributes

Attributes of <button>
AttributeRole
typesubmit sends a form, reset restores initial values, button has no built-in action.
disabledPrevents interaction with the button.
name / valueIncluded when this button submits its form.

Example HTML code

<form action="forms.html#tag-button" method="get">
  <label for="reset-topic">Edit this text, then reset</label>
  <input id="reset-topic" type="text" name="topic" value="HTML">
  <button type="reset">Reset example</button>
  <button type="submit">Submit sample topic</button>
</form>

Result Live preview

<textarea>

05

Definition

Provides a multi-line plain-text input. Its initial value is placed between the tags.

Attributes

Attributes of <textarea>
AttributeRole
nameThe key used for its submitted value.
rows / colsThe initial visible size in text rows and columns.
maxlengthThe maximum permitted number of characters.
requiredRequires a value before form submission.

Example HTML code

<label for="practice-notes">Practice notes</label>
<textarea id="practice-notes" name="notes" rows="4" maxlength="200">Today I learned about HTML.</textarea>

Result Live preview

<select>

06

Definition

Offers a set of options for the user to choose from.

Attributes

Attributes of <select>
AttributeRole
nameThe submitted field name.
multipleAllows more than one selected option.
requiredRequires a non-empty selection before submission.

Example HTML code

<label for="select-topic">Study topic</label>
<select id="select-topic" name="topic">
  <option value="">Choose a topic</option>
  <option value="html">HTML</option>
  <option value="css">CSS</option>
</select>

Result Live preview

<option>

07

Definition

Defines one choice within a select, optgroup or datalist.

Attributes

Attributes of <option>
AttributeRole
valueThe value submitted for this choice.
selectedSelects the option initially in a select.
disabledMakes this option unavailable.

Example HTML code

<label for="option-level">Level</label>
<select id="option-level" name="level">
  <option value="beginner" selected>Beginner</option>
  <option value="advanced">Advanced</option>
</select>

Result Live preview

<optgroup>

08

Definition

Groups related options inside a select element.

Attributes

Attributes of <optgroup>
AttributeRole
labelThe visible name of the group.
disabledDisables all options in the group.

Example HTML code

<label for="group-topic">Course</label>
<select id="group-topic" name="course">
  <optgroup label="Frontend">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
  </optgroup>
  <optgroup label="Backend">
    <option value="python">Python</option>
  </optgroup>
</select>

Result Live preview

<fieldset>

09

Definition

Groups related controls and their labels. A legend names the group.

Attributes

Attributes of <fieldset>
AttributeRole
disabledDisables descendant controls, except those inside the first legend.
formAssociates the group with a form by its id.

Example HTML code

<fieldset>
  <legend>Study preference</legend>
  <label><input type="radio" name="study-mode" value="solo" checked> Solo</label>
  <label><input type="radio" name="study-mode" value="pair"> In a pair</label>
</fieldset>

Result Live preview

Study preference

<legend>

10

Definition

Provides the caption for a fieldset. Place it as the first child of that fieldset.

Attributes

Attributes of <legend>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<fieldset>
  <legend>Favourite topics</legend>
  <label><input type="checkbox" name="favourite-html" value="yes"> HTML</label>
  <label><input type="checkbox" name="favourite-css" value="yes"> CSS</label>
</fieldset>

Result Live preview

Favourite topics

<datalist>

11

Definition

Supplies suggested values to an input. Users can still enter a different value.

Attributes

Attributes of <datalist>
AttributeRole
idMust match the associated input’s list attribute.

Example HTML code

<label for="browser-input">Browser</label>
<input id="browser-input" type="text" name="browser" list="browser-options">
<datalist id="browser-options">
  <option value="Chrome"></option>
  <option value="Firefox"></option>
  <option value="Safari"></option>
</datalist>
