HTML forms

Forms let a user enter text, choose an option and press a button.

<form>

Definition

Groups inputs and sends their values when the user presses Submit.

Attributes

AttributeRole
actionThe page that receives the values.
methodget puts values in the URL; post sends them in the request body.

Example (code)

<form action="forms.html" method="get">
  <label for="topic">Topic:</label>
  <input id="topic" type="text" name="topic">
  <button type="submit">Send</button>
</form>

Example (result)

This example reloads this page with the topic in the URL. It does not save the answer.

<label>

Definition

Adds a name to an input. Click the label to select its input.

Attributes

AttributeRole
forMust match the id of the input.

Example (code)

<label for="student-name">Student name:</label>
<input id="student-name" type="text">

Example (result)

<input>

Definition

Creates an input, such as a text box or a checkbox.

Attributes

AttributeRole
typeThe input type, for example text.
nameThe name of the field when the form is sent.

Example (code)

<label for="name">Name:</label>
<input id="name" type="text" name="name">

Example (result)

<textarea>

Definition

Creates a text box with several lines.

Attributes

AttributeRole
rowsThe number of visible text lines.
nameThe name used when sending the text.

Example (code)

<label for="message">Message:</label>
<textarea id="message" name="message" rows="3"></textarea>

Example (result)

<select>

Definition

Creates a drop-down list.

Attributes

AttributeRole
nameThe name used when sending the selected value.

Example (code)

<label for="subject">Subject:</label>
<select id="subject" name="subject">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
</select>

Example (result)

<option>

Definition

Creates one choice inside a select list.

Attributes

AttributeRole
valueThe value sent when this option is chosen.
selectedSelects the option when the page opens.

Example (code)

<label for="language">Language:</label>
<select id="language" name="language">
  <option value="en" selected>English</option>
  <option value="uz">Uzbek</option>
</select>

Example (result)

<button>

Definition

Creates a clickable button.

Attributes

AttributeRole
typesubmit sends a form; reset restores its starting values.

Example (code)

<form action="forms.html" method="get">
  <label for="reset-topic">Topic:</label>
  <input id="reset-topic" type="text" name="topic" value="HTML">
  <button type="submit">Send</button>
  <button type="reset">Reset</button>
</form>
