Text formatting

Use these tags to write headings, paragraphs and formatted text.

<h1> to <h6>

Definition

Headings show the structure of a page. h1 is the main heading; h2 to h6 are smaller heading levels.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<h1>Main heading</h1>
<h2>Section heading</h2>
<h3>Level 3 heading</h3>
<h4>Level 4 heading</h4>
<h5>Level 5 heading</h5>
<h6>Level 6 heading</h6>

Example (result)

Main heading

Section heading

Level 3 heading

Level 4 heading

Level 5 heading
Level 6 heading

<p>

Definition

Creates a paragraph of text.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>I am learning HTML.</p>

Example (result)

I am learning HTML.

<br>

Definition

Starts a new line inside a paragraph. It has no closing tag.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Hello!<br>Welcome to my website.</p>

Example (result)

Hello!
Welcome to my website.

<hr>

Definition

Separates two topics, usually with a horizontal line.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>First topic.</p>
<hr>
<p>Second topic.</p>

Example (result)

First topic.

Second topic.

<strong>

Definition

Marks important text. It usually looks bold.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p><strong>Remember</strong> to save your file.</p>

Example (result)

Remember to save your file.

<em>

Definition

Adds emphasis to a word. It usually looks italic.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>I <em>really</em> like HTML.</p>

Example (result)

I really like HTML.

<b>

Definition

Draws attention to text without adding extra importance. It usually looks bold.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Topic: <b>HTML</b>.</p>

Example (result)

Topic: HTML.

<i>

Definition

Marks a term or a phrase in another voice or language. It usually looks italic.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>The word <i>element</i> is an HTML term.</p>

Example (result)

The word element is an HTML term.

<u>

Definition

Marks an annotation, such as a spelling mistake. It usually adds an underline.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Check the spelling: <u>paragraf</u>.</p>

Example (result)

Check the spelling: paragraf.

<mark>

Definition

Highlights text that is relevant to the reader.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Today we study <mark>HTML</mark>.</p>

Example (result)

Today we study HTML.

<sub>

Definition

Shows text below the normal line, for example in a chemical formula.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Water: H<sub>2</sub>O.</p>

Example (result)

Water: H2O.

<sup>

Definition

Shows text above the normal line, for example a power in maths.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Area: x<sup>2</sup>.</p>

Example (result)

Area: x2.

<code>

Definition

Marks a short piece of computer code.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>Use <code>&lt;p&gt;</code> for a paragraph.</p>

Example (result)

Use <p> for a paragraph.

<pre>

Definition

Keeps spaces and line breaks as they are written in the code.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<pre><code>&lt;p&gt;Hello!&lt;/p&gt;
&lt;p&gt;Welcome!&lt;/p&gt;</code></pre>

Example (result)

<p>Hello!</p>
<p>Welcome!</p>
