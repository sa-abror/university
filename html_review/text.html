Definition

Attributes of <h1>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

AttributeRole

<del>

20

Definition

Records text removed from a document.

Attributes

Attributes of <del>
AttributeRole
datetimeWhen the deletion was made, in a machine-readable date/time format.
citeA URL explaining the change.

Example HTML code

<p>Meeting day: <del datetime="2026-09-25">Monday</del> Tuesday.</p>

Result Live preview

Meeting day: Monday Tuesday.

<blockquote>

22

Definition

Contains an extended quotation from another source. Place the attribution outside the quotation.

Attributes

Attributes of <blockquote>
AttributeRole
citeThe URL of the quoted source; this attribute does not display an attribution.

Example HTML code

<blockquote cite="https://www.w3.org/mission/">
  <p>Making the web work — for everyone.</p>
</blockquote>
<p>— W3C</p>

Result Live preview

Making the web work — for everyone.

— W3C

<abbr>

24

Definition

Represents an abbreviation. An optional title supplies its full expansion.

Attributes

Attributes of <abbr>
AttributeRole
titleThe full form of the abbreviation.

Example HTML code

<p><abbr title="HyperText Markup Language">HTML</abbr> structures a page.</p>

Result Live preview

HTML structures a page.

The title may appear on hover. Also explain abbreviations in visible text when readers need the expansion.

<pre>

27

Definition

Preserves whitespace and line breaks. It is often combined with code to display formatted source code.

Attributes

Attributes of <pre>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<pre><code>&lt;h1&gt;Hello&lt;/h1&gt;
&lt;p&gt;Welcome.&lt;/p&gt;</code></pre>

Result Live preview

<h1>Hello</h1>
<p>Welcome.</p>

AttributeRole

Result Live preview
