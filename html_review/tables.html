HTML tables

Use a table to show data in rows and columns.

<table>

Definition

Creates a table with rows and columns.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<table>
  <tbody>
    <tr><th scope="col">Name</th><th scope="col">Subject</th></tr>
    <tr><td>Ali</td><td>HTML</td></tr>
  </tbody>
</table>

Example (result)

NameSubject
AliHTML

<caption>

Definition

Adds a title to a table.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<table>
  <caption>My subjects</caption>
  <thead>
    <tr><th scope="col">Subject</th><th scope="col">Hours</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>2</td></tr>
    <tr><td>CSS</td><td>1</td></tr>
  </tbody>
  <tfoot>
    <tr><th scope="row">Total</th><td>3</td></tr>
  </tfoot>
</table>
