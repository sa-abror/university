CHAPTER 05 / 09 Tables

Make data readable.

Describe relationships between rows and columns with accessible headings and a clear caption.

8 tag guidesCode + live examplesHTML & CSS

In this chapter

<table>

01

Definition

Organizes tabular data into rows and columns. Use CSS, rather than a table, to lay out a page.

Attributes

Attributes of <table>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<table>
  <caption>Study plan</caption>
  <tbody>
  <tr><th scope="col">Topic</th><th scope="col">Day</th></tr>
  <tr><td>HTML</td><td>Monday</td></tr>
  <tr><td>CSS</td><td>Tuesday</td></tr>
  </tbody>
</table>

<caption>

02

Definition

Gives a table its title or explanation. It is the first child of the table element.

Attributes

Attributes of <caption>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<table>
  <caption>Available courses</caption>
  <tbody>
  <tr><th scope="col">Course</th><th scope="col">Places</th></tr>
  <tr><td>Web development</td><td>20</td></tr>
  </tbody>
</table>

<thead>

03

Definition

Groups the header rows of a table. Use th elements for the actual header cells.

Attributes

Attributes of <thead>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<table>
  <caption>Modules</caption>
  <thead>
    <tr><th scope="col">Module</th><th scope="col">Hours</th></tr>
  </thead>
  <tbody><tr><td>HTML</td><td>4</td></tr></tbody>
</table>

<tfoot>

05

Definition

Groups summary or total rows after the table body.

Attributes

Attributes of <tfoot>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<table>
  <caption>Study hours</caption>
  <thead><tr><th scope="col">Topic</th><th scope="col">Hours</th></tr></thead>
  <tbody><tr><td>HTML</td><td>4</td></tr></tbody>
  <tfoot><tr><th scope="row">Total</th><td>4</td></tr></tfoot>
</table>

<th>

07

Definition

Defines a header cell that describes other cells in its row or column.

Attributes

Attributes of <th>
AttributeRole
scopeIdentifies the related cells: row, col, rowgroup or colgroup.
colspan / rowspanThe number of columns or rows covered by the cell.
idAn identifier that complex data cells can reference with headers.

Example HTML code

<table>
  <caption>HTML lesson</caption>
  <tbody>
  <tr><th scope="col">Topic</th><th scope="col">Level</th></tr>
  <tr><th scope="row">HTML</th><td>Beginner</td></tr>
  </tbody>
</table>

<td>

08

Definition

Contains one data value in a table row.

Attributes

Attributes of <td>
AttributeRole
colspanHow many columns the cell spans.
rowspanHow many rows the cell spans.
headersIDs of the header cells associated with this cell.

Example HTML code

<table>
  <caption>Weekly schedule</caption>
  <tbody>
  <tr><th scope="col">Monday</th><th scope="col">Tuesday</th></tr>
  <tr><td colspan="2">HTML workshop</td></tr>
  </tbody>
</table>
