HTML Review

This website explains the main HTML tags. Choose a topic from the menu and try the examples.

Each tag has a definition, an attributes table, example code and its result.

<!DOCTYPE html>

Definition

Tells the browser that this is a modern HTML document. It is a declaration, not a tag.

Attributes

AttributeRole
NoneThis declaration has no attributes.

Example (code)

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My first page</title>
  <link rel="stylesheet" href="../css/style.css">
</head>
<body class="example-page">
  <h1>Hello, HTML!</h1>
  <p>This is my first web page.</p>
</body>
</html>

Example (result)

Open the example page

The doctype is the first line. It does not show any text on the page.
