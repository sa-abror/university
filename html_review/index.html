HTML Review

This website explains the main HTML tags. Choose a topic from the menu and try the examples.

<!DOCTYPE html>

Definition

Tells the browser that this is a modern HTML document. It is a declaration, not a tag.

Attributes

AttributeRole
NoneThis declaration has no attributes.

Example (code)

<!DOCTYPE html>

Example (result)

This page uses HTML5. The declaration does not display any text.

<html>

Definition

Contains the whole HTML page: the head and the body.

Attributes

AttributeRole
langSets the language, for example en for English.

Example (code)

<html lang="en">

Example (result)

This page is an HTML document with English as its language.

This is the opening tag already used at the top of this page.

<head>

Definition

Contains the page title and other information for the browser.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<head>
  <title>Home | HTML Review</title>
</head>

Example (result)

Look at the browser tab: Home | HTML Review.

The head is already used at the top of this file. It is not visible page content.

<body>

Definition

Contains the content that we see on the page.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<body>
  <p>Hello, HTML!</p>
</body>

Example (result)

Hello, HTML!

This paragraph is inside the body of the current page. A page has only one body.
