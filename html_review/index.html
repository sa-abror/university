<!DOCTYPE html>

01

Definition

The doctype declaration tells the browser to use modern standards mode. It is a declaration, rather than an HTML element, and belongs before the root element.

Attributes

Attributes of <!DOCTYPE html>
AttributeRole
NoneThe HTML doctype has no attributes.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>An HTML document</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <h1>Hello, HTML.</h1>
  <p>This is a complete document.</p>
</body>
</html>

Result Live preview

The declaration is not visible; the browser renders the document that follows it.

<html>

02

Definition

The root element contains the document head and body. Its language helps browsers and assistive technology interpret the page.

Attributes

Attributes of <html>
AttributeRole
langThe language of the document, such as en.
dirText direction: ltr, rtl or auto.

Example HTML code

<!DOCTYPE html>
<html lang="en" dir="ltr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>An HTML document</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <p>This document is written in English.</p>
</body>
</html>

Result Live preview

<head>

03

Definition

Contains document metadata, including its title and links to resources. Content in the head is not the visible page body.

Attributes

Attributes of <head>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My first page</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <p>The title and stylesheet are set in the head.</p>
</body>
</html>

Result Live preview

The framed document has its own head. Its title is used as document metadata, not as a visible heading.

<body>

04

Definition

Contains the content displayed in the browser, including headings, paragraphs, images and forms.

Attributes

Attributes of <body>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>An HTML document</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <h1>Inside the body</h1>
  <p>This is the visible page content.</p>
</body>
</html>

Result Live preview
