HTML lists

Lists help us show steps, groups of items and definitions.

<ul>

Definition

Creates a list with bullet points.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

Example (result)

  • HTML
  • CSS

<ol>

Definition

Creates a numbered list.

Attributes

AttributeRole
startThe number of the first item.
typeThe numbering style, for example 1, A or a.

Example (code)

<ol>
  <li>Create a file.</li>
  <li>Write some HTML.</li>
  <li>Open it in a browser.</li>
</ol>

Example (result)

  1. Create a file.
  2. Write some HTML.
  3. Open it in a browser.

<li>

Definition

Creates one item inside a ul or ol list.

Attributes

AttributeRole
valueSets the item number inside an ol list.

Example (code)

<ul>
  <li>My first item</li>
  <li>My second item</li>
</ul>

Example (result)

  • My first item
  • My second item

<dl>

Definition

Creates a list of terms and their descriptions.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<dl>
  <dt>HTML</dt>
  <dd>A language for building web pages.</dd>
</dl>

Example (result)

HTML
A language for building web pages.
