CHAPTER 04 / 09 Lists

Put things in order.

Use unordered, ordered and description lists to make related information easier to scan.

6 tag guidesCode + live examplesHTML & CSS

In this chapter

<ul> <ol> <li> <dl> <dt> <dd>

<ul>

01

Definition

Groups items whose order does not change their meaning. Each item is an li element.

Attributes

Attributes of <ul>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>Images</li>
</ul>

Result Live preview

  • HTML
  • CSS
  • Images

<ol>

02

Definition

Groups items in a meaningful sequence. Browsers usually number the items.

Attributes

Attributes of <ol>
AttributeRole
startThe integer to start counting from.
reversedCounts in descending order.
typeThe marker type: 1, a, A, i or I.

Example HTML code

<ol start="2">
  <li>Write the HTML.</li>
  <li>Connect the stylesheet.</li>
  <li>Test in a browser.</li>
</ol>

Result Live preview

  1. Write the HTML.
  2. Connect the stylesheet.
  3. Test in a browser.

<li>

03

Definition

Represents one item inside an ordered or unordered list.

Attributes

Attributes of <li>
AttributeRole
valueSets an item’s ordinal value when its parent is ol.
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<ol>
  <li>Introduction</li>
  <li value="5">Chapter five</li>
  <li>Chapter six</li>
</ol>

Result Live preview

  1. Introduction
  2. Chapter five
  3. Chapter six

<dl>

04

Definition

Contains groups of terms and their descriptions, such as a glossary.

Attributes

Attributes of <dl>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<dl>
  <dt>HTML</dt>
  <dd>The structure of a page.</dd>
  <dt>CSS</dt>
  <dd>The presentation of a page.</dd>
</dl>

Result Live preview

HTML
The structure of a page.
CSS
The presentation of a page.

<dt>

05

Definition

Identifies a term or name in a description list.

Attributes

Attributes of <dt>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<dl>
  <dt>Element</dt>
  <dd>A part of an HTML document.</dd>
</dl>

Result Live preview

Element
A part of an HTML document.

<dd>

06

Definition

Provides the description or value for a preceding term in a description list.

Attributes

Attributes of <dd>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<dl>
  <dt>Attribute</dt>
  <dd>Additional information written in an opening tag.</dd>
</dl>

Result Live preview

Attribute
Additional information written in an opening tag.
