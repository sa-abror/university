<header>

01

Definition

Contains introductory content for a page or section, such as a heading and navigation. It does not create a new section by itself.

Attributes

Attributes of <header>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<header>
  <h3>HTML study journal</h3>
  <p>A little practice every day.</p>
</header>

Result Live preview

HTML study journal

A little practice every day.

<nav>

02

Definition

Identifies a major group of navigation links. Give distinct navigation regions descriptive accessible names.

Attributes

Attributes of <nav>
AttributeRole
aria-labelAn accessible name distinguishing this navigation region.
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<nav aria-label="Example chapters">
  <a href="index.html">Home</a>
  <a href="text.html">Text</a>
  <a href="forms.html">Forms</a>
</nav>

Result Live preview

Home Text Forms

<main>

03

Definition

Identifies the dominant content of a document. A page should have only one main element that is not hidden.

Attributes

Attributes of <main>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>An HTML document</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body class="document-example">
  <main>
    <h1>Today’s lesson</h1>
    <p>Choose meaningful HTML elements.</p>
  </main>
</body>
</html>

Result Live preview

This example runs in its own document so the review page keeps a single main landmark.

<section>

04

Definition

Groups related content into a thematic section, normally identified by a heading. Use div when grouping is only for styling.

Attributes

Attributes of <section>
AttributeRole
aria-labelledbyReferences the id of a heading that names this section.
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<section aria-labelledby="section-heading">
  <h3 id="section-heading">Learning objectives</h3>
  <p>Build a multi-page HTML website.</p>
</section>

Result Live preview

Learning objectives

Build a multi-page HTML website.

<span>

09

Definition

A generic inline container. It groups a small part of text for styling or another attribute without creating a block.

Attributes

Attributes of <span>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

Result Live preview

This lesson is in progress.

<details>

10

Definition

Creates a disclosure widget that users can expand and collapse. Its summary is the visible label.

Attributes

Attributes of <details>
AttributeRole
openExpands the content initially.
nameGroups disclosures so only one in the named group is open.

Example HTML code

<details>
  <summary>What is semantic HTML?</summary>
  <p>HTML that describes the meaning of its content.</p>
</details>

Result Live preview

What is semantic HTML?

HTML that describes the meaning of its content.

<summary>

11

Definition

Provides the visible label for a details disclosure. Place it as the first child of details.

Attributes

Attributes of <summary>
AttributeRole
idA unique identifier, also used as a link destination.
classOne or more class names that CSS can select.

Example HTML code

<details open>
  <summary>Try closing this example</summary>
  <p>The summary remains visible when this text is hidden.</p>
</details>

Result Live preview

Try closing this example

The summary remains visible when this text is hidden.
