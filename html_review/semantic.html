Semantic and layout tags

Semantic tags explain the purpose of each part of a page.

<header>

Definition

Contains the introduction to a page or section.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<header>
  <h3>My website</h3>
  <p>Welcome to my page!</p>
</header>

Example (result)

My website

Welcome to my page!

<nav>

Definition

Groups the main navigation links.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<nav>
  <a href="index.html">Home</a>
  <a href="text.html">Text</a>
</nav>

Example (result)

Home Text

<main>

Definition

Contains the main content of a page. Use one visible main element per page.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<main>
  <h2>Main content</h2>
  <p>This is the main part of the page.</p>
</main>

Example (result)

Main content

This is the main part of the page.

<section>

Definition

Groups content about one topic, usually with a heading.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<section>
  <h3>About me</h3>
  <p>I am a first-year student.</p>
</section>

Example (result)

About me

I am a first-year student.

<footer>

Definition

Contains information at the end of a page or section.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<footer>
  <p>Created for HTML Lab Work 3.</p>
</footer>

Example (result)

Created for HTML Lab Work 3.

<div>

Definition

Groups elements in a block. It does not give them a special meaning.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<div class="box">
  <p>This is a simple box.</p>
</div>

Example (result)

This is a simple box.

<span>

Definition

Groups a small part of text, for example to change its colour.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>I am learning <span class="highlight">HTML</span>.</p>

Example (result)

I am learning HTML.
