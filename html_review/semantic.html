Semantic and layout tags

Semantic tags explain the purpose of each part of a page.

<header>

Definition

Contains the introduction to a page or section.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<header>
  <h3>My website</h3>
  <p>Welcome to my page!</p>
</header>

Example (result)

My website

Welcome to my page!

<nav>

Definition

Groups the main navigation links.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<nav aria-label="Example menu">
  <a href="index.html">Home</a>
  <a href="text.html">Text</a>
</nav>

Example (result)

Home Text

<main>

Definition

Contains the main content of a page. Use one visible main element per page.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<main>
  <h1>My lesson</h1>
  <p>Today I am learning HTML.</p>
</main>

Example (result)

Open the example page

The result opens a small example page so we do not put a main element inside another main.

<section>

Definition

Groups content about one topic, usually with a heading.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<section>
  <h3>About me</h3>
  <p>I am a first-year student.</p>
</section>

Example (result)

About me

I am a first-year student.

Attributes

AttributeRole

<article>
  <h3>My first lesson</h3>
  <p>Today I created an HTML page.</p>

Example (result)

My first lesson

Today I created an HTML page.

<aside>

Definition

Contains extra information related to the main content.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<aside aria-label="Example tip">
  <h3>Tip</h3>
  <p>Save your file before opening it.</p>
</aside>

Example (result)

Tip

Save your file before opening it.

Attributes

idGives the element a unique name.
classConnects the element to a CSS class.

<div>

Definition

Groups elements in a block. It does not give them a special meaning.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<div class="box">
  <p>This is a simple box.</p>
</div>

Example (result)

This is a simple box.

<span>

Definition

Groups a small part of text, for example to change its colour.

Attributes

AttributeRole
idGives the element a unique name.
classConnects the element to a CSS class.

Example (code)

<p>I am learning <span class="highlight">HTML</span>.</p>

Example (result)

I am learning HTML.
