## 2. Как читать HTML

```html
<h3 class="highlight">My heading</h3>
```

- `<h3>` — открывающий тег. Он создаёт заголовок третьего уровня.
- `class="highlight"` — атрибут. Здесь он связывает элемент с классом в CSS.
- `My heading` — содержимое элемента.
- `</h3>` — закрывающий тег. Слеш `/` показывает конец элемента.

Большинство элементов имеют открывающий и закрывающий теги.
У `br`, `img`, `input`, `meta`, `link` и `source` закрывающего тега нет.
Вложенные элементы закрываем изнутри наружу: `<p><b>Hello</b></p>`.

## 3. Структура документа и информация для браузера

| Запись | Что делает |
| --- | --- |
| `<!DOCTYPE html>` | Сообщает браузеру, что это современный HTML-документ. Это объявление, а не обычный тег. |
| `<html>` | Содержит весь документ: `head` и `body`. |
| `<head>` | Содержит настройки страницы. Это не видимая шапка сайта. |
| `<meta>` | Передаёт браузеру настройки: например, кодировку и ширину страницы на телефоне. |
| `<title>` | Задаёт название вкладки браузера. |
| `<link>` | Подключает другой ресурс. У нас подключает файл CSS. |
| `<body>` | Содержит то, что посетитель видит на странице. |

Простой документ:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>HTML Review</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>HTML Review</h1>
  <p>My first website.</p>
</body>
</html>
```

`lang="en"` означает, что язык страницы — английский; это не переводит текст.
`charset="UTF-8"` позволяет правильно читать символы, в том числе русские буквы.
Настройка `viewport` делает ширину страницы равной ширине экрана устройства
и задаёт начальный масштаб `1`.
`rel="stylesheet"` объясняет, что подключаемый файл — таблица стилей.

В корневом `index.html` есть дополнительная строка:

```html
<meta http-equiv="refresh" content="0; url=html_review/index.html">
```

Она открывает главную страницу сайта с задержкой `0` секунд.
На страницах учебника `html`, `head` и `body` уже используются в самом документе.
Поэтому в блоках результата объясняется их действие, без вставки второго документа внутрь первого.

## 4. Заголовки и текст

| Тег | Что делает |
| --- | --- |
| `<h1>` | Главный заголовок страницы, первый уровень. |
| `<h2>` | Заголовок раздела, второй уровень. У нас это название изучаемого тега. |
| `<h3>` | Заголовок подраздела, третий уровень. У нас это `Definition`, `Attributes` и `Example`. |
| `<h4>` | Заголовок четвёртого уровня, для подраздела внутри третьего. |
| `<h5>` | Заголовок пятого уровня. |
| `<h6>` | Заголовок шестого уровня. |
| `<p>` | Создаёт абзац текста. |
| `<br>` | Переносит текст на новую строку внутри одного блока. |
| `<b>` | Привлекает внимание к тексту, обычно делает его жирным. |
| `<strong>` | Обозначает важный текст, обычно тоже жирный. |
| `<i>` | Выделяет термин или фразу, например на другом языке; обычно курсивом. |
| `<em>` | Обозначает смысловое ударение; обычно отображается курсивом. |

Уровень заголовка выбираем по смыслу. Размер шрифта можно отдельно изменить через CSS.
`h3` сам ничего не запускает: он обозначает заголовок третьего уровня.

```html
<h2>HTML tags</h2>
<h3>Definition</h3>
<p>This is a paragraph.<br>This is a new line.</p>
<p><strong>Remember:</strong> save your file.</p>
```

## 5. Что делают pre, code и специальные символы

| Тег | Что делает |
| --- | --- |
| `<pre>` | Сохраняет введённые пробелы и переносы строк. У нас это блок с примером кода. |
| `<code>` | Обозначает фрагмент компьютерного кода. Обычно использует шрифт с одинаковой шириной символов. |

`code` не запускает код и не превращает вложенные HTML-теги в обычный текст автоматически.
Поэтому для показа HTML используем специальные записи — сущности:

| Запись в HTML | Что увидит посетитель |
| --- | --- |
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&amp;` | `&` |

Например, так показываем код абзаца:

```html
<pre><code>&lt;p&gt;Hello!&lt;/p&gt;</code></pre>
```

Посетитель увидит текст `<p>Hello!</p>`. А так показываем результат:

```html
<div class="result">
  <p>Hello!</p>
</div>
```

Посетитель увидит обычный абзац `Hello!`.
В нашем CSS длинные строки в `pre` дополнительно переносятся, чтобы помещаться на телефоне.

## 6. Ссылки, изображения и мультимедиа

| Тег | Что делает |
| --- | --- |
| `<a>` | Создаёт ссылку. Адрес записываем в `href`. |
| `<img>` | Показывает изображение. Путь к файлу записываем в `src`. |
| `<audio>` | Добавляет аудиоплеер. |
| `<video>` | Добавляет видеоплеер. |
| `<source>` | Указывает файл и его тип внутри `audio` или `video`. Можно указать несколько источников для выбора браузером. |

```html
<a href="text.html">Text</a>
<img src="images/study-desk.svg" alt="Study desk" width="400">
<audio controls src="images/chime.wav"></audio>
<video controls width="400" src="images/html-demo.webm"></video>
```

`alt` — текстовое описание картинки, в том числе для тех, кто её не видит.
`controls` добавляет кнопки воспроизведения. Без него стандартные кнопки плеера не показываются.
`width="400"` задаёт ширину в пикселях, а CSS ограничивает её шириной доступного места.
В нашем видео нет звука; в аудио звучат три короткие ноты.

## 7. Списки и таблицы

| Тег | Что делает |
| --- | --- |
| `<ul>` | Создаёт список с маркерами, обычно точками. |
| `<ol>` | Создаёт нумерованный список. |
| `<li>` | Создаёт один пункт внутри `ul` или `ol`. |
| `<table>` | Создаёт таблицу. |
| `<tr>` | Создаёт строку таблицы. |
| `<th>` | Создаёт ячейку заголовка, например `Attribute`. |
| `<td>` | Создаёт обычную ячейку с данными. |

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
</ul>

<table>
  <tr><th>Attribute</th><th>Role</th></tr>
  <tr><td>href</td><td>Link address</td></tr>
</table>
```

В примере таблицы две строки и два столбца.
Теги `th` и `td` находятся внутри `tr`, а строки — внутри `table`.

## 8. Формы

| Тег | Что делает |
| --- | --- |
| `<form>` | Объединяет поля и кнопки в форму. |
| `<label>` | Создаёт подпись к полю. При правильной связи нажатие на подпись выбирает поле. |
| `<input>` | Создаёт поле ввода. Вид поля зависит от атрибута `type`. |
| `<textarea>` | Создаёт поле для текста из нескольких строк. |
| `<select>` | Создаёт выпадающий список. |
| `<option>` | Создаёт один вариант внутри `select`. |
| `<button>` | Создаёт кнопку. Её действие зависит от `type`. |

```html
<form action="forms.html" method="get">
  <label for="topic">Topic:</label>
  <input type="text" id="topic" name="topic">
  <button type="submit">Send</button>
</form>
```

`for="topic"` у подписи совпадает с `id="topic"` у поля: так они связаны.
`name="topic"` задаёт имя отправляемого значения.
Если ввести `CSS` и нажать `Send`, откроется `forms.html?topic=CSS`.
Форма учебная: она добавляет значение в адрес страницы и не сохраняет его в базе данных.
Кнопка с `type="reset"` возвращает поля своей формы к исходным значениям.

## 9. Части страницы

| Тег | Что делает |
| --- | --- |
| `<header>` | Шапка страницы или раздела. У нас содержит название сайта. |
| `<nav>` | Объединяет ссылки основного меню. |
| `<main>` | Основное содержание страницы. На странице должен быть один видимый `main`. |
| `<section>` | Раздел на одну тему, обычно с заголовком. |
| `<footer>` | Подвал страницы или раздела. У нас содержит название работы, авторов и ссылку на GitHub. |
| `<div>` | Обычный блок для группировки элементов, без специального смысла. |
| `<span>` | Обёртка для небольшого фрагмента текста, например для его окрашивания. |

`head` и `header` — разные теги: первый содержит настройки, второй — видимую шапку.
Названия `header`, `nav` и `footer` объясняют назначение частей страницы, а их внешний вид задаёт CSS.

```html
<p>I am learning <span class="highlight">HTML</span>.</p>
```

Здесь `span` позволяет выделить только слово `HTML`.
Общая оболочка содержания сайта — `div class="content"`.
Тег `main` отдельно показан в примере на странице `semantic.html`.

## 10. Атрибуты из проекта

Атрибуты уточняют работу тега. Их пишут внутри открывающего тега.
Некоторые атрибуты перечислены в таблицах учебника, но не включены в короткие примеры.

| Атрибут | Что означает |
| --- | --- |
| `class` | Имя класса для CSS. Один класс может использоваться у многих элементов. |
| `id` | Уникальный идентификатор элемента на странице. Используется, например, для связи поля с подписью. |
| `lang` | Язык текста: `en` — английский, `ru` — русский. |
| `charset` | Кодировка документа, у нас `UTF-8`. |
| `name` | В `meta` — имя настройки; в поле формы — имя отправляемого значения. |
| `content` | Значение настройки у `meta`. |
| `http-equiv` | Вид инструкции браузеру у `meta`. У нас `refresh` перенаправляет с корневой страницы. |
| `rel` | Связь с подключаемым ресурсом. `stylesheet` означает файл стилей. |
| `href` | Адрес ссылки у `a` или путь к подключаемому файлу у `link`. |
| `src` | Путь к картинке, аудио или видео. |
| `alt` | Текстовое описание изображения. |
| `width` | Ширина картинки или видео. |
| `controls` | Показывает стандартные кнопки плеера. |
| `loop` | Повторяет аудио или видео после окончания. |
| `poster` | Изображение перед началом воспроизведения видео. |
| `type` | В `input` — вид поля; в `button` — действие кнопки; в `source` — тип медиафайла; в `ol` — вид нумерации. |
| `start` | Начальный номер списка `ol`. |
| `value` | В полях, кнопках и `option` — значение; в `li` внутри `ol` — номер пункта. |
| `colspan` | На сколько столбцов растягивается ячейка таблицы. |
| `rowspan` | На сколько строк растягивается ячейка таблицы. |
| `action` | Адрес, куда отправляется форма. |
| `method` | Способ отправки формы. У нас `get`: значения попадают в адрес страницы. |
| `for` | Указывает `id` поля, к которому относится `label`. |
| `rows` | Начальное количество видимых строк в `textarea`. |
| `selected` | Делает `option` выбранным по умолчанию. |

`controls`, `loop` и `selected` — логические атрибуты: наличие атрибута включает его действие.
Например, пишем `controls`, а для отключения удаляем его, а не пишем `controls="false"`.

## 11. Как устроен CSS

Все правила находятся в [html_review/css/style.css](html_review/css/style.css).
В HTML нет атрибута `style` и блока `<style>`.

```css
.highlight {
  color: #c8f29a;
  font-weight: bold;
}
```

`.highlight` — селектор: он выбирает элементы с `class="highlight"`.
В фигурных скобках находятся свойства и значения. Двоеточие отделяет свойство от значения,
а точка с запятой завершает запись. Здесь текст становится зелёным и жирным.

### Селекторы, которые встречаются в нашем файле

| Селектор | Что выбирает |
| --- | --- |
| `*` | Все элементы. |
| `body` | Элемент `body`. Так же работают селекторы `a`, `table`, `pre` и другие названия тегов. |
| `.tag` | Все элементы с классом `tag`. Точка означает класс. |
| `h1, h2, h3` | Сразу три вида заголовков. Запятая объединяет селекторы. |
| `.hero-stats p` | Все абзацы внутри блока со счётчиками на главной. Пробел означает «внутри». |
| `.footer-credits a` | Все ссылки внутри блока с авторами. |
| `.content > h1` | Только `h1`, который находится непосредственно внутри `.content`. |
| `.tag > h3` | Только заголовки `h3` самой карточки, без заголовков внутри её примеров. |
| `.menu a:hover` | Ссылку в меню, на которую наведён указатель мыши. |
| `.menu .active` | Элемент с классом `active` внутри меню. |
| `input[type="text"]` | Поля `input`, у которых `type` равен `text`. |
| `body::before`, `body::after` | Декоративные слои перед содержимым и после него. У нас они создают фон без дополнительных HTML-тегов. |
| `.tag > h2::before` | Номер перед названием тега. |
| `a:focus-visible` | Ссылку, на которую перешли с клавиатуры. Показываем вокруг неё заметную рамку. |
| `.window-dots span:nth-child(2)` | Второй кружок в верхней части окна с кодом. |
| `.tag:nth-of-type(2)` | Карточку, которая является вторым элементом своего типа среди соседей. Используется для задержки появления. |
| `::selection` | Текст, который посетитель выделил мышью или клавиатурой. |

`:hover` — встроенное состояние CSS.
`.active` — наше имя класса: на каждой HTML-странице вручную отмечена её ссылка в меню.

### Как читать значения

- `16px` — 16 пикселей, единица размера в CSS.
- `width: 92%` — ширина составляет 92% от ширины содержащего блока.
- `max-width: 1120px` — блок не станет шире 1120 пикселей.
- `margin: 64px auto 88px` — сверху отступ 64 пикселя, снизу 88; слева и справа отступы автоматически распределяются поровну.
- `padding: 9px 16px` — сверху и снизу 9 пикселей, слева и справа 16.
- `border: 1px solid #c8f29a24` — полупрозрачная сплошная рамка толщиной 1 пиксель. `dashed` означает пунктирную рамку.
- `border: 0` — убрать рамку.
- `box-shadow: 0 12px 35px #00000020` — тень без сдвига по горизонтали, со сдвигом вниз на 12 пикселей и размытием 35 пикселей.
- `#c8f29a` — шестнадцатеричная запись светло-зелёного цвета.
- `#c8f29a24` — тот же цвет с прозрачностью, которую задают последние две цифры.
- `clamp(34px, 5vw, 54px)` — размер зависит от ширины экрана, но остаётся между 34 и 54 пикселями. `1vw` — 1% ширины окна браузера.
- `radial-gradient(...)` — градиент, расходящийся от центра; так сделаны мягкие световые пятна.
- `linear-gradient(...)` — переход цветов вдоль прямой; так оформлены карточки.

## 12. Как работают анимации

Всё движение создаёт CSS. Картинки, видео или JavaScript для анимации фона не нужны.

| Анимация | Где используется |
| --- | --- |
| `background-drift` | Медленно сдвигает и увеличивает градиентные пятна на фоне. |
| `appear` | Проявляет заголовок и карточки, одновременно немного поднимая их. |
| `editor-float` | Плавно поднимает и слегка поворачивает окно с кодом на главной. |
| `blink` | Показывает и скрывает полоску рядом с «Hello, world.». |

Пример из нашего CSS:

```css
@keyframes appear {
  from { opacity: 0; transform: translateY(18px); }
  to { opacity: 1; transform: translateY(0); }
}
```

`from` — начало движения, `to` — конец.
Сначала блок прозрачный и сдвинут вниз на 18 пикселей.
Потом он становится видимым и возвращается на своё место.
В других анимациях `0%`, `50%` и `100%` обозначают начало, середину и конец.
`rotate(-1deg)` поворачивает блок на один градус, `scale(1.08)` увеличивает на 8%.
`translate3d(x, y, z)` сдвигает фон по трём осям; в нашем случае третье значение равно нулю.

```css
.hero-copy {
  animation: appear 0.8s ease-out both;
}
```

- `appear` — имя анимации.
- `0.8s` — длительность 0,8 секунды.
- `ease-out` — движение замедляется к концу.
- `both` — сохраняет начальное оформление во время задержки и конечное после завершения.
- В карточках `backwards` применяет начальное оформление только до запуска; после появления работают обычные стили и наведение.
- У фона `infinite` повторяет движение бесконечно, а `alternate` меняет его направление после каждого прохода.
- `ease-in-out` делает начало и конец движения плавными.
- `steps(2, jump-none)` у курсора переключает видимость двумя шагами.

Карточки появляются при открытии страницы. Наведение поднимает их на несколько пикселей
и подсвечивает рамку. Эти короткие изменения делает `transition`.

### Что означают media-запросы

`@media` включает CSS-правила только при определённых условиях:

- `max-width: 900px` — на экранах шириной до 900 пикселей окно с кодом переходит под текст.
- `max-width: 600px` — уменьшаются отступы и заголовки; меню перестаёт прилипать к верху, чтобы не закрывать маленький экран.
- `hover: hover` — эффекты наведения включаются на устройствах, где можно навести указатель.
- `prefers-reduced-motion: reduce` — если пользователь уменьшил движение в настройках устройства, анимации и плавная прокрутка отключаются.

`!important` в последнем правиле даёт отключению движения приоритет над остальными правилами анимации.
Если браузер не поддерживает размытие фона меню, его полупрозрачная заливка всё равно остаётся видимой.

## 13. Как связаны файлы и примеры

Пути считаются относительно файла, в котором они написаны:

- `href="text.html"` — перейти к странице в той же папке.
- `href="css/style.css"` — подключить CSS из подпапки `css`.
- `src="images/chime.wav"` — загрузить аудио из подпапки `images`.
- `href="#basics"` — перейти к блоку этой же страницы с `id="basics"`.
- Адрес, начинающийся с `https://`, ведёт к ресурсу в интернете.

На всех девяти страницах одинаковые шапка, меню и подвал.
В каждой карточке есть определение тега, таблица `Attribute / Role`,
пример внутри `pre` и `code`, а затем его результат в браузере.
Шапка и подвал записаны в каждом HTML-файле отдельно: если меняем подпись авторов,
обновляем её во всех девяти файлах.
